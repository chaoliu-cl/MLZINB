# Capital Bikeshare: frozen specification before ML-ZINB fitting

This candidate was selected after the Riphahn-Wambach-Million health-panel discovery joint test failed (.0706615). Its individual inflation screen was nominally significant, but it was not substituted for the joint test. No RWM validation outcomes were modeled. A county-murder panel was downloaded and documented but no moderation model was fitted. The current example concerns human mobility/transportation behavior, a social-science application, not a clinical dataset.

Source: UCI Bike Sharing dataset, Fanaee-T and Gama, Washington DC Capital Bikeshare hourly casual-user counts, 2011-2012. Natural hierarchy: recorded one-hour slots within calendar days. Workingday is constant by day; midday (10:00-15:59) varies within day. Question: Does a working day modify the within-day midday versus other-hour association with casual rental counts? The window was chosen from the calendar before outcome-model fitting; it is not optimized. Exploratory descriptive counts by these cells have been inspected and remain recorded.

Use all released hourly records without imputing absent hours as zeros. Outcome is casual-user rentals, not unique people. Each record is a recorded one-hour aggregation. No population or registered-rental exposure is invented. Never control for total rentals (which contains the outcome).

Discovery is all 2011 days; temporal validation is all 2012 days. Neither formulas nor exclusions may be changed using validation tests. The preselected joint moderation criterion is .05 in discovery and validation; the full-sample estimates are secondary. The search includes two fitted primary candidate questions; report both and provide a conservative Bonferroni comparison (.025) for the selected example. Validation is a temporal check in the same system, not an independent-city replication.

Within/between decomposition: midday_w = midday minus its observed-day mean; midday_b = observed-day mean minus .25. Context: workingday (0/1). A person-level context from the earlier health candidate is not being relabeled as a geographic context here: this application has day-level context.

Primary count component: midday_w + midday_b * workingday + first two sine/cosine hour harmonics + month indicators + normalized temperature and its square + humidity + wind speed + bad-weather indicator, with a day random intercept. Primary inflation component: midday_w + midday_b * workingday + first hour harmonic + temperature + humidity + bad-weather indicator. Bad weather combines documented codes 3 and 4 because code 4 has only three records. Predictor variables use released normalized units. The inflation equation is intentionally smaller because zeros are rare in some daytime cells.

Fit matched NB2 ML-ZINBs: additive, count interaction only, inflation interaction only, and both. Add the midday_w:workingday term to the specified component(s). Fit a same-count-specification NB2 comparator; no ordinary boundary chi-square NB-versus-ZINB test. Test additive versus both (2 df), then conditional and isolated component additions. Inspect convergence, Hessian, gradients, coefficient magnitudes and SEs. No selection of a result by favorable optimizer.

Uncertainty: day-cluster sandwich scores including nuisance parameters, independently reconstructed against the glmmTMB Laplace likelihood. Also report calendar-time HAC covariance (14-day Bartlett lags, missing dates represented rather than collapsed) for serial dependence between adjacent days. Full-sample inference does not supersede the held-out test.

Predictions: all four quantities mu, pi, E(Y), total-zero probability, computed recordwise with day random effects zero. Reference distributions must be described. Show supported 24-hour curves by workingday, pointwise intervals, additive overlays and standardized midday contrast changes. Do not vary midday independently from clock hour. Between-day coverage means remain fixed when changing the time of day. A changing response-scale contrast alone is not interaction evidence.

Diagnostics: 500 unconditional simulations, observed/simulated zero, positive counts and mean calibration by day type and hour band, individual and day-aggregated residuals. Plot contextual support, distributions, component slopes/interaction modifiers and time-residual dependence.

Sensitivity: day random slope for midday; day inflation intercept; full hour-factor count main effect (drop the redundant midday_w main effect, which is spanned by hour indicators and midday_b); more flexible inflation harmonics and month terms; quadratic temperature by workingday adjustment; complete-24-record days; alternate BFGS optimizer. Any numerical or substantive failure remains recorded. If a richer adequate model removes the focal interaction, do not call the primary result robust.

Influence: first-order deletion approximation for every day, with exact reoptimized deletions for the five highest-ranked days and five outcome-independent evenly spaced dates. Do not describe approximations as exact refits or multiplier uncertainty as a whole-group refit bootstrap. This toolkit permits a verified sandwich/HAC uncertainty method instead of an expensive refit bootstrap.

Limits: one city/system; recorded hours may exclude absent/zero-total hours and documentation does not resolve every reason; daylight-saving changes; growth and temporal dependence; no inventory/exposure data; day type not randomized; latent structural-zero state is a mixture construct rather than a verified non-rental mechanism. Check missing-hour sensitivity. A supported interaction establishes an association under a stated model, not a causal contextual mechanism.
