# Final Integrated Manuscript Materials

This folder integrates the retained Add Health, MEPS, CCD LEA, and
comprehensive simulation analyses. The CCD rurality analysis is designated as
the final third empirical application because it provides a stable joint model
with opposite-signed interactions in the count and inflation components.

Contents:

- `integrated_methods_results.md`: editable manuscript source.
- `integrated_methods_results.docx`: Word manuscript.
- `integrated_methods_results.pdf`: rendered manuscript.
- `table_empirical_results.csv`: primary empirical evidence summary.
- `table_ccd_nested_comparisons.csv`: CCD selected-model comparisons.
- `table_simulation_design.csv`: comprehensive simulation scenarios.
- `figures/`: manuscript figures copied from the reproducible analyses.

The simulation files retained in `03_SIMULATION` include the complete
22-condition, seven-model design and its execution pilot. A larger Monte Carlo
run is still required before using selection, coverage, power, or type I error
rates as publication-level numerical estimates.
